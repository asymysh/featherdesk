# Project Context

> ⚠️ **HISTORICAL — superseded by `specs/`.** The documents under `conductor/`
> describe the **original Go prototype** (Go 1.26 + cgo + WebSocket + single
> binary, 5 tracks) — the working reference that lives on the
> `feature-libav-vp8s8` branch. The project has since been **redesigned in Rust**
> (dlopen + `abi_stable` add-on model). The **authoritative architecture is
> `specs/CENTRAL_SPEC.md`** and the module specs under `specs/`. These conductor
> files are retained only as historical planning/decision artifacts; where they
> disagree with `specs/`, `specs/` wins. Track-status markers below reflect the
> Go prototype's progress, not the Rust effort.
